# Reference corpus

`general_english.txt` is plain UTF-8 text of general English, used as the baseline when scoring
which words and 2-3 word phrases are distinctive for a speaker (log-odds ratio). It is not
committed; supply your own. Transcribed speech works best (talk radio, podcasts, parliamentary
or congressional records, many different speakers). A few million words is plenty.

Any text works in a pinch, for example public-domain books from Project Gutenberg, but written
prose makes conversational filler ("you know", "i mean") look more distinctive than it is.
